# GSSI Lectures

Teaching materials and interactive lecture resources for courses at the Gran Sasso Science Institute (GSSI).

This repository collects lecture material organized by course category. Each course folder contains the most up-to-date version of the corresponding teaching material.

## Course Categories

- [Immigration Courses](immigration-courses/)
- [Core Courses](core-courses/)
- [Advanced Courses](advanced-courses/)

## Structure

```text
gssi-lectures/
├── immigration-courses/
├── core-courses/
└── advanced-courses/
```

Course materials may include lecture notes, slides, interactive Jupyter Book content, exercises, examples, and supporting resources.
